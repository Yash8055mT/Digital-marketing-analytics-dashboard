# CampaignPulse — Digital Marketing Campaign Dashboard

CampaignPulse is a responsive front-end dashboard designed to demonstrate digital marketing operations and campaign reporting skills.

## Features

- Campaign and channel filters
- KPI cards for spend, impressions, clicks, conversions, CTR, and cost per conversion
- Channel spend visualization
- Campaign conversion visualization
- Campaign performance table with ROAS
- Automatically generated operational insights
- CSV report export
- Responsive design
- Light/dark theme toggle

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Sample campaign data

## How to Run

1. Download or clone the repository.
2. Open `index.html` in a browser.
3. Use the filters to explore campaign performance.
4. Click **Export report CSV** to download the selected data.
